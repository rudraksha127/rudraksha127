# Computer Science Foundations & Interview Preparation Map

This is a learning and revision map for SDE preparation. Listing a topic here means it is part of the study plan; it does not imply expert-level proficiency.

## Data structures

- Arrays, strings, matrices, and dynamic arrays
- Hash maps, sets, and frequency counting
- Linked lists
- Stacks, queues, deques, and monotonic structures
- Binary trees, binary search trees, and balanced-tree concepts
- Heaps and priority queues
- Graph representations, disjoint-set union, and tries

## Algorithmic patterns

- Sorting, searching, and binary search on the answer
- Two pointers and sliding window
- Prefix sums, difference arrays, and hashing
- Fast/slow pointers and linked-list manipulation
- Tree and graph traversals: DFS, BFS, topological ordering
- Greedy methods and interval scheduling
- Recursion, backtracking, and state-space search
- Dynamic programming: memoization, tabulation, state transitions
- Shortest paths, minimum spanning trees, and union-find applications

## Complexity and problem-solving method

1. Restate the problem and confirm input constraints.
2. Start with a correct baseline approach.
3. Identify the dominant operation and bottleneck.
4. Derive time and space complexity.
5. Test empty, smallest, largest, duplicate, sorted, and adversarial inputs.
6. Explain why the optimized approach is correct.
7. Implement readable code and validate it with targeted tests.

## Object-oriented programming

- Encapsulation, abstraction, inheritance, polymorphism
- Composition, interfaces, and dependency inversion
- Object lifecycle, immutability, and responsibility boundaries
- SOLID principles and when not to over-engineer

## Database management systems

- Relational modelling and normalization
- Joins, indexes, constraints, and query plans
- Transactions, ACID properties, isolation, and concurrency anomalies
- SQL vs document data models and workload-driven trade-offs
- Schema migration, backup, and recovery concepts

## Operating systems

- Processes, threads, context switching, and scheduling
- Synchronization, mutexes, semaphores, and deadlocks
- Virtual memory, paging, and memory allocation
- Filesystems, I/O, and resource management

## Computer networks

- TCP/IP, DNS, HTTP/HTTPS, TLS, and proxies
- TCP connection lifecycle and transport-layer trade-offs
- Latency, throughput, bandwidth, and congestion
- REST constraints, caching headers, and client/server communication

## System design foundations

- Functional and non-functional requirements
- Capacity assumptions and bottleneck identification
- API contracts, data models, and component boundaries
- Caching, queues, asynchronous work, and consistency
- Availability, fault tolerance, observability, and graceful degradation
- Security and privacy as cross-cutting design constraints
