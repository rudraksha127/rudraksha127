# Credential Publication & Verification Policy

Professional credentials are useful only when a reviewer can identify the issuer and verify the award.

## Required fields before a credential is published

| Field | Requirement |
|---|---|
| Credential title | Exact title shown by the issuer |
| Issuer | Official issuing organisation |
| Credential URL | Public issuer verification page, when available |
| Credential ID | Public ID only; never publish private account or access data |
| Issue date | As shown by the issuer |
| Expiry date | Include when the credential expires |
| Status | Active, expired, or not publicly verifiable |

## Publication rules

- Do not infer a certification from course completion, exam preparation, or a badge image.
- Do not use a certification count unless every item in the count is verified and current.
- Do not alter official credential names to sound more senior.
- Do not publish screenshots containing email addresses, account identifiers, or private profile details.
- If an issuer provides no public verification page or shareable credential identifier, exclude the credential from the public profile until an independently verifiable record is available.

The profile README will include credential entries only when a reviewer can independently verify the award through an issuer-controlled record. Course completion and unverified badge images are not sufficient.
